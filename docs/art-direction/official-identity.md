# Official Game of Worlds identity

The canonical mark is `public/images/brand/game-of-worlds-mark.svg`: a gold orbital world with a white satellite on a dark field. Pair it with the shared `official-wordmark` text style from `public/css/brand.css`. Do not invent page-specific diamonds, G/W initials, or substitute faction crests for the game mark.

Use an empty image alt when the containing link already names Game of Worlds. The in-game mark links to the lobby; public-page marks link home. Keep the mark visible on mobile.

`public/favicon.ico` (16, 32, 48 and 64 pixels), the 180-pixel Apple touch icon, and the 512-pixel sharing image are raster derivatives of this same SVG. Regenerate all derivatives together when the canonical drawing changes. Every public HTML document references the same SVG and ICO favicons using absolute paths so nested guide and lore pages work correctly.

Palette: ink `#0b121c`, gold `#e5bf7e`, white `#f5f7fa`. Wordmark: Segoe UI/system sans-serif, weight 750, slight tracking. Keep it flat, clear and legible; no embossed gradients, glow or scanlines over the identity.
